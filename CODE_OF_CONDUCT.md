# Code of Conduct

This repository is maintained by one person and does not accept code contributions
(see [`CONTRIBUTING.md`](CONTRIBUTING.md)). What it does accept - reports that a published claim is
wrong - works best under a few plain expectations.

## What is expected

- **Argue about the measurement, not the person.** A disagreement over a number, a date, or a
  described behaviour is settled by measuring it again, in public, with the method stated.
- **Say what you actually checked.** "I ran this and got that" carries the discussion. "This looks
  wrong" does not, and neither does an appeal to authority - including the maintainer's.
- **Being right is not a licence to be unpleasant**, and being wrong is not a failing. Several
  claims in [`CORRECTIONS.md`](CORRECTIONS.md) were published here confidently and were false.

## What is not accepted

Harassment, personal attacks, discriminatory language, deliberate misrepresentation of what
someone said, and publishing private information. Also: opening issues to advertise a product.

## Scope

This applies to issues, pull requests, discussions, commit messages, and any communication that
references this repository - including a report sent through the private security channel.

## Enforcement

The maintainer will remove or edit content that breaches this document, and may block an account
from the repository. Where a decision is contestable, the reasoning will be stated rather than
left implicit.

To report a breach - including one by the maintainer - use the private security channel described
in [`SECURITY.md`](SECURITY.md), or open an issue if the matter is already public.

## Attribution

This document is deliberately short and specific to this repository rather than adapted from a
standard template, because a template that does not describe how a project actually works is worse
than none.
